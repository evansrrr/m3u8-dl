# M3U8 下载器

纯网页的 HLS（m3u8）下载与预览工具：零后端、零安装，解析、下载、合并与保存全部在浏览器本地完成。可部署到 Cloudflare Pages、Vercel、GitHub Pages 或任意静态服务器。

基于 [caiweiming/get-m3u8](https://github.com/caiweiming/get-m3u8)（MIT）修改，主要增强：

- **MP4 / TS 双格式**：默认 MP4（mux.js 浏览器内转封装），可切换 TS，无实验开关。
- **跨域注入下载**：源站禁止 CORS 时，把一段代码贴进源站控制台，即可在同源上下文下载。
- **极简黑白界面**：主题跟随系统深浅色。
- **中英双语**：界面语言跟随系统，中文系统显示中文，其余语言一律英文，跨域面板同步切换。
- **剪贴板识别**：复制 m3u8 链接后回到本页，自动打开新建下载并填入。

## 功能

- 解析媒体播放列表与多清晰度（master）播放列表，可选分辨率。
- 在线预览，支持外部音轨与 WebVTT 字幕。
- AES-128 加密分片解密。
- 全部下载，或按分片序号指定范围。
- FIFO 任务队列，单任务并发 1–8（默认 4），显示速度与进度。
- 分片级失败重试；连续前缀强制合并导出。
- 快捷参数：`?source=...&format=mp4&concurrency=4`。

## 使用

### 常规下载

1. 打开“新建下载”，粘贴 m3u8 地址；剪贴板中已有 m3u8 链接时会自动填入。
2. 选择格式（TS / MP4）、下载范围与并发数；有多个清晰度时先选分辨率。
3. 下载完成后浏览器自动保存文件。

### 跨域下载

源站禁止跨域时：

1. 在“新建下载”弹窗中点击“复制跨域代码”。
2. 打开视频源站页面，按 `F12` 打开控制台，粘贴代码并回车。
3. 页面右下角出现“M3U8 注入下载”面板，粘贴地址、选择格式后下载。

注入面板在源站同源上下文运行，自带解析、AES-128 解密与 MP4 转封装，不依赖主工具页。

## 部署

纯静态站点，无构建步骤，第三方库已随附在 `vendor/`。

- **Cloudflare Pages**：连接仓库 → 框架预设 `None`，构建命令留空，输出目录 `/`。
- **Vercel**：导入仓库 → 框架预设 `Other`，构建命令与输出目录留空。
- **本地**：

```bash
python -m http.server 4173   # 打开 http://127.0.0.1:4173/
```

建议通过 HTTPS 或 localhost 访问：剪贴板读取等能力依赖安全上下文；以 `file://` 直接打开时浏览器无法保存剪贴板授权，自动填入会停用，只能手动粘贴。

## 限制

- 播放列表、密钥与分片须允许浏览器访问；跨域受限时使用上述注入方案。
- DRM 保护、需登录或依赖特定请求头 / Cookie 的资源通常无法下载。
- 分片保存在页面内存，刷新或关闭页面会丢失未完成任务。
- 请仅下载你拥有访问与保存权限的内容，并遵守服务方条款与适用法律。
