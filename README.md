# M3U8 下载器

纯网页的 HLS（m3u8）下载与预览工具，零后端、零安装，解析、下载、合并与保存全部在浏览器本地完成，可部署到 Cloudflare Pages、Vercel、GitHub Pages 或任意静态服务器

基于 [caiweiming/get-m3u8](https://github.com/caiweiming/get-m3u8)（MIT）修改，主要增强：

- **MP4 / TS 双格式**
- **边下边存**：TS 直接追加，MP4 逐段转封装写入，长视频不再占满内存
- **跨域注入下载**：嗅探地址、清晰度选择、边下边存
- **界面显示**
- **中英双语**
- **剪贴板识别**

并解决了原项目 MP4 格式视频时长显示问题

## 功能

- 解析媒体播放列表与多清晰度播放列表，可选分辨率
- 在线预览，支持外部音轨与 WebVTT 字幕
- AES-128 加密分片解密
- 全部下载，或按分片序号指定范围
- FIFO 任务队列，单任务并发 1–8，显示速度与进度
- 分片级失败重试；连续前缀强制合并导出
- 任务行显示已下载大小与预计剩余时间
- 快捷参数：`?source=...&format=mp4&concurrency=4`

## 使用

### 常规下载

1. 打开“新建下载”，粘贴 m3u8 地址；剪贴板中已有 m3u8 链接时会自动填入
2. 可编辑标题，选择格式（TS / MP4）、下载范围与并发数，有多个清晰度时可选分辨率
3. 下载完成后浏览器自动保存文件

### 跨域下载

源站禁止跨域时：

1. 在“新建下载”弹窗中点击“复制跨域代码”；已填写地址时会一并带入
2. 打开视频源站页面，按 `F12` 打开控制台，粘贴代码并回车
3. 页面右下角出现“M3U8 注入下载”面板，地址栏已自动填入页面最近的 m3u8 请求

注入面板在源站同源上下文运行，自带解析、AES-128 解密、fMP4 拼接与 MP4 转封装，不依赖其他页面：

- 自动嗅探页面已请求的 m3u8（performance / fetch / XHR / `video` 元素），点击候选即可切换
- 粘贴地址后先走查播放列表，显示分片数与总时长；多清晰度时按码率排序可选
- 分片级失败自动重试（4xx 不重试），并发 2–12 可调，显示速度与剩余时间
- 支持 `#EXT-X-MAP`（fMP4 直接拼接为 MP4）与 `#EXT-X-BYTERANGE`（Range 请求）
- 边下边存：勾选后先选保存位置，分片按序写入磁盘，长视频不占内存（需 Chrome/Edge 等支持文件选择器的浏览器）
- 面板可拖动、可收起，位置与偏好本地记忆，深浅色跟随系统

## 部署

纯静态站点，无构建步骤，第三方库随附于 `vendor/`

- **Cloudflare Pages**：连接仓库 → 框架预设 `None`，构建命令留空，输出目录 `/`
- **Vercel**：导入仓库 → 框架预设 `Other`，构建命令与输出目录留空
- **本地**：

```bash
python -m http.server 4173   # http://127.0.0.1:4173/
```

以 `file://` 打开时自动填入会停用

## 限制

- 播放列表、密钥与分片须允许浏览器访问；跨域受限时使用上述注入方案
- 注入面板不合并外部音轨（`#EXT-X-MEDIA:TYPE=AUDIO`），也不支持 SAMPLE-AES / DRM，遇到这类源请回到主工具页
- DRM 保护、需登录或依赖特定请求头或 Cookie 的资源通常无法下载
- 未开启边下边存时，分片缓存在页面内存，刷新或关闭页面会丢失未完成任务；开启后分片直接写入文件
- MP4 统一输出为分片式（fMP4）：每片一个 moof+mdat，播放器拖动进度条可按片定位，比整段大分片更跟手；个别老旧播放器不支持该结构，可改用 TS
- 选择了外部音轨或字幕的任务会自动回退到缓存模式，因为这类任务需要额外写出独立文件
- 请仅下载你拥有访问与保存权限的内容，并遵守服务方条款与适用法律
